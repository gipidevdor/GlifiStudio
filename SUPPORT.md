# Supporto

Glifi Studio è in sviluppo privato. Supporto pubblico e compatibilità tra versioni
non sono ancora garantiti.

## Scegliere la segnalazione

| Per | Modello |
| --- | --- |
| Riprodurre un problema | Difetto |
| Proporre una funzione | Proposta di funzionalità |
| Discutere una scelta strutturale | Decisione architetturale |
| Correggere o completare un documento | Documentazione |

## Prima di inviare

- verificare la revisione di `main` e l'ambiente Xcode 27;
- cercare issue già esistenti;
- riprodurre il problema con dati sintetici e minimizzati;
- non allegare corpus, documenti reali, credenziali o dati personali;
- allegare log solo dopo averli controllati e ripuliti da informazioni riservate.

Per vulnerabilità o possibili incidenti, seguire il
[canale di sicurezza](SECURITY.md).
